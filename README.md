# いろロジック（初級版）

3×3グリッド・3色（赤・黄・青）のカラー数独パズル。各行・各列に3色をちょうど1個ずつ配置するシンプルなロジックパズルです。幼児〜低学年向けに、数字を使わず色だけで成立する直感的なルールにしています。

## ルール

- 各行（横）に 🔴赤・🟡黄・🔵青 がちょうど1個ずつ
- 各列（縦）に 🔴赤・🟡黄・🔵青 がちょうど1個ずつ
- 数学的には「3次ラテン方陣」に等価で、全問が唯一解

## 特徴

- **全20問**（easy 7 / medium 7 / hard 6）を一直線で出題（進捗 x/20）
- **唯一解保証** — 3次ラテン方陣を全列挙し、各問のヒント配置が唯一解になることを検証済み
- **色覚多様性（CVD）対応** — 各色に模様（赤=斜線 / 黄=ドット / 青=横線）を付与し、色だけに依存しない
- **レスポンシブ** — スマートフォン／タブレット／PC に対応（タッチ・マウス両対応）

## 技術スタック

- React 18 + Vite
- Tailwind CSS
- 状態管理は `useState` のみ
- テスト: Vitest

## 開発

```bash
npm install      # 依存インストール
npm run dev      # 開発サーバ（http://localhost:5173/）
npm test         # ルール検証・パズルデータの自動テスト
npm run build    # 本番ビルド（dist/）
npm run preview  # ビルド結果のプレビュー
```

## パズルデータの生成

パズルは静的データ（`src/data/puzzles.js`）で、Python スクリプトから生成・検証しています。

```bash
python tools/gen_puzzles.py   # 全12種のラテン方陣を列挙し、唯一解を検証して再生成
```

## 設計メモ

ルール検証（`utils/validate.js`）は行/列をベタ書きせず、「制約グループ（線＝セルの集合）のリストを検証する」汎用関数として実装しています。将来の3次元版（3×3×3 を層スライスで表現するラテン立方）へ、検証ロジックと状態管理をそのまま拡張できる設計です。

## ランキング（サーバーレスAPI）

全20クリアの合計タイムを名前付きで保存・表示できます。`api/scores.js`（Vercel サーバーレス関数）が保存と取得を担当します。

- `GET /api/scores` … 上位ランキング（速い順）
- `POST /api/scores` … スコア保存（全20クリアのみ受付）

保存先は環境変数があれば Upstash Redis（Vercel KV）、なければインメモリ（一時・非永続）にフォールバックします。永続化するには以下のいずれかを設定してください（Vercel で Upstash/KV を接続すると自動注入されます）。

```
KV_REST_API_URL / KV_REST_API_TOKEN
# または
UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN
```

なお、プレイヤー名はブラウザの localStorage に保存され、閉じても保持されます。

## デプロイ

Vite ビルドをそのまま静的ホスティングできます（Vercel 等）。`api/` 配下はサーバーレス関数として自動デプロイされます。
